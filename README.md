# 愤怒小鸟下100层

一个纯 HTML/CSS/JavaScript 实现的竖版下坠小游戏：玩法复刻经典 Flash 小游戏
《是男人就下100层》（NS-SHAFT），美术采用《愤怒的小鸟》卡通画风（Canvas 2D
矢量绘制，无任何外部图片/音频资源，无构建工具，离线可玩）。

## 运行方式

任选其一：

1. **直接双击** `index.html`（推荐 Chrome / Edge）
2. 本地服务器：
   ```bash
   cd Demo_man_jump
   python -m http.server 8642
   # 浏览器打开 http://127.0.0.1:8642/index.html
   ```

## 玩法

- **目标**：不断向下跳层，下到第 **100 层** 即胜利
- **操作**：
  - `←` `→` 或 `A` `D`：左右移动（不能跳跃，靠平台缝隙下坠）
  - `空格` / `回车`：开始 / 结算后重开
  - `R`：随时重置本局
  - 界面右上角 **⟳ 重置** 按钮：鼠标重置
  - 🔊 按钮 / `M`：音效开关（WebAudio 合成音效）
  - 触屏设备：按住画布左右半边移动
- **威胁**：顶部尖刺天花板持续下压，越深越快；被顶到会快速扣血
- **鹈鹕骑士**：开局 **5 秒**后，一只骑着自行车的鹈鹕会从顶部冲出来——一只翅膀扶车把，
  另一只翅膀抡着一条大鱼，在顶上来回巡逻并周期性朝你俯冲；
  **被抡着的鱼碰到就直接判负**（看到"!!"预警赶紧横移躲开）
  - 鹈鹕的自行车**起步飞快、越骑越慢**，骑行 **2~5 秒就会散架**（2s:3s:4s:5s 概率 4:3:2:1），
    车轮、车架、羽毛、大鱼四处飞溅——鹈鹕死了不影响小鸟，纯属它自己倒霉
  - 鹈鹕同样**怕顶部尖刺天花板**：地图滚上去把它压到就撞碎
  - 阵亡后隔 4~8 秒会再派一只新鹈鹕；debuff"鹈鹕+N"召唤的每一只也都遵守上述生命周期
- **魔性 buff 广告**：屏幕两侧是会"从下往上漂"的土味广告位（椰树椰汁风），
  广告卡从底部升起、升到顶部没点就消失、无限循环，**点击即领取**：
  - 🛡 无敌 3 / 5 / 10 秒——免疫钉板、天花板尖刺、甚至鹈鹕的鱼（金色护盾环）
  - 🐌 缓速 3 / 5 秒——地图滚动速度大幅降低（×0.25），天花板急刹车
  - ⚠️ **小心紫色陷阱卡**（"🎁神秘大奖"）：加速 1 / 2 / 3 秒——地图滚动 ×2.2，
    天花板贴脸俯冲；鹈鹕+1 / +2 / +3——当场召唤额外骑车鹈鹕（全场上限 6 只）！
    陷阱卡与好卡同款魔性样式，点前看清颜色和名字
  - 手快有手慢无，"仅剩 N 秒"是真的会消失！
- **五种平台**（愤怒的小鸟材质）：

| 平台 | 材质 | 行为 |
|---|---|---|
| 普木板 | 木板（木纹+钉） | 安全站立，缓慢回血 |
| 草皮板 | 草皮+泥土 | 落上一次回复 3 格血 |
| 冰板 | 半透明冰块 | 踩上 0.45 秒后碎裂坠落 |
| 传送带 | 石头履带 | 站上去会被推向箭头方向 |
| 钉板 | 木板+金属尖刺 | 落上扣 2 格血，久站持续扣血 |

- **难度曲线**：深度越深 → 天花板下压越快、平台越窄、钉板/冰板/传送带越多

## 文件结构

```
Demo_man_jump/
  index.html        页面骨架（canvas、HUD、重置按钮、遮罩层）
  css/style.css     卡通风格 UI
  js/art.js         全部美术绘制（色板/胖红/平台/背景/粒子）
  js/game.js        游戏逻辑（物理/生成/HP/计层/输入/音效/调试参数）
  reference/        官方参考图 + 美术规格 ART_SPEC.md（fw 多模态分析产出）
  debug/            各状态截图 + 两轮美术评审报告
```

## 调试参数（URL Query）

| 参数 | 效果 |
|---|---|
| `?floor=97` | 从第 97 层直接开局（快速验证胜利流程） |
| `?debug=stage&floor=70` | 渲染第 70 层进行中画面并冻结（截图用） |
| `?debug=ads` | 确定性摆卡：左金卡+右蓝卡广告冻结展示（截图用） |
| `?debug=pelican` | 立即出生鹈鹕骑士（`&n=3` 数量、`&pf=-1` 朝左、`&crash=1` 立即散架、`&freeze=1` 冻结，截图用） |
| `?nopelican=1` | 本局禁用鹈鹕（测试用） |
| `?debug=gallery` | 静态展示全部 5 种平台 + 下落中的胖红（截图用） |
| `?debug=win` / `?debug=lose&floor=37` | 直接渲染胜利 / 失败画面 |

页面暴露调试钩子：`window.__game`（游戏状态对象）、`window.__restart()`（重置）。
